# Análise de Dados de RH com Power BI

Dashboard desenvolvido no Power BI para análise de dados de Recursos Humanos, explorando indicadores relacionados ao perfil dos funcionários, funções, salários, experiência, envolvimento no trabalho e disponibilidade para hora extra.

##  Ferramentas utilizadas

- Power BI
- Power Query
- DAX

##  Indicadores analisados

- Total de funcionários
- Distribuição por gênero
- Salário médio
- Experiência média
- Funcionários por função
- Envolvimento no trabalho
- Disponibilidade para hora extra
- Faixa etária
